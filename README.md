# 🏋️ Gym ERP AI Smart Search

An AI-powered natural language search system for a Gym ERP application, built using Python, Streamlit, Pandas, NumPy, and Scikit-learn.

## 🚀 Features

- 🔎 Natural Language Search
- 🤖 AI-based module detection
- 📊 Gym ERP data search and filtering
- 🎯 TF-IDF based text matching
- 📈 Cosine Similarity based ranking
- 🗂️ Multiple ERP modules
- 🖥️ Interactive Streamlit dashboard

## 🧩 ERP Modules

- Gym Members
- Membership Plans
- Gym Trainers
- Attendance Log
- Payments & Fees
- Fitness Centers & Facilities
- Equipment Suppliers
- Expenses & Accounts
- Employees / Staff
- Reports & Analytics
- Settings

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- TF-IDF
- Cosine Similarity

## 🔍 How It Works

The system allows users to search Gym ERP data using natural language.

### Search Pipeline

User Query  
↓  
Text Cleaning  
↓  
Module Detection  
↓  
Metadata Filtering  
↓  
TF-IDF Ranking  
↓  
Cosine Similarity  
↓  
Relevant Results
